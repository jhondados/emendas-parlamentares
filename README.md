# 🏛️ Análise de Emendas Parlamentares

> Análise de emendas parlamentares com IA. Rastreia destino dos recursos, mede execução e identifica padrões suspeitos de alocação.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/emendas-parlamentares/

[![Vertical](https://img.shields.io/badge/Vertical-Governança-blue)]() [![IA](https://img.shields.io/badge/IA-ML-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]()

## 📊 Resultados-chave (KPIs)
**42K** Emendas · **R$ 38B** Recursos · **67%** Execução · **240** Alertas

## 🧠 Tecnologias de IA
ML · NLP · Network Analysis

## ✨ O que faz
- Rastreamento de recursos
- Taxa de execução por emenda
- Análise de rede parlamentar
- Detecção de padrões

## 🗄️ Fonte de dados real
[Portal da Transparência + SIOP](https://portaldatransparencia.gov.br)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Portal da Transparência + SIOP
2. **Processamento com IA** — ML · NLP · Network Analysis
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
